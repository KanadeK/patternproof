# Changelog

All notable changes are documented here. Versioning follows Semantic Versioning.

## [0.1.0] - 2026-08-30

### Added

- strict version-one pattern JSON and bounded image loading;
- deterministic per-cell CIELAB D65 / CIE76 classification;
- `match`, `background`, `empty`, `wrong`, and `uncertain` evidence;
- atomic JSON, CSV, PNG overlay, and standalone HTML reports;
- stable CLI exit codes for clean, findings, and invalid runs;
- generated clean/defect examples and cross-platform release gates.
